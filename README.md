# Autonomous Logistics Mule UGV
Autonomous Logistics Mule UGV is an all-terrain logistics 'mule' that follows an operator in challenging terrain, carrying up to 5 kg of supplies. 
The robot uses a 4 terrain classification CNN to adapt its speed and drive strategy (rocky/grass/sand/mud), and a vision-based 'follow-me' tracker locks onto the operator's high-visibility vest
pattern. Operator can also command 'go to GPS waypoint' for autonomous resupply runs.
